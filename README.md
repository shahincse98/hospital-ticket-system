# CareFlow - Hospital Smart Ticket & Queue Management System

A modern, responsive, and real-time hospital OPD & consultation token/queue management web application.

## 🌟 Key Features

1. **Patient Self-Service Kiosk:**
   - Easy OPD token generation with department selection.
   - Emergency & Senior Citizen priority pass.
   - Printable digital slip with queue wait estimate and QR code.

2. **Doctor / Counter Console:**
   - Multi-counter / department switching.
   - One-click "Call Next Patient", "Repeat Voice Call", "Skip" or "Completed".
   - Direct patient calling from queue table.

3. **Waiting Hall Live TV Display:**
   - High-contrast, large-format spotlight display for called tokens.
   - Live department status counters and bottom queue ticker.
   - Automated voice announcements and chime bells via browser Web Speech API.

4. **Multi-Tab / Device Synchronization:**
   - Uses LocalStorage & BroadcastChannel API for real-time synchronization between screens.

## 🛠️ Tech Stack
- HTML5, Modern CSS (Glassmorphism, Dark Mode)
- Vanilla JavaScript (ES6+, Web Speech API, Web Audio API)
